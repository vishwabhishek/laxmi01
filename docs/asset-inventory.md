## 1. Asset Strategy & Optimization

The reference website uses high-resolution photographic storytelling to convey artisan woodworking quality:
- **Formats**: 85% WebP format (optimal compression), 10% Scalable Vector Graphics (SVG), 5% High-Res JPEG.
- **Resolution Strategy**: Full-width banners scale up to `3440px` and `7360px` with Webflow responsive `srcset` breakpoints (500w, 800w, 1080w, 1600w, 2000w).
- **Rule Enforcement**: Per prompt instructions, **original visual assets have been preserved and downloaded directly**. No generic stock images or unrelated AI slop have been substituted.
